# Sound effects and ambience

Every file here is **original**: it is synthesised from noise, filters and oscillators by
`scripts/gen-sfx.js` (run `npm run sfx`). There are no third-party recordings, so there is no licence to track.
The output is deterministic, so regenerating gives identical files.

| File | Type | Used when |
|---|---|---|
| ocean, rain, storm, wind, forest, suspense | Seamless loops (11–13 s) | The scene's setting (keywords in English or Arabic, or the world's default) |
| thunder, footsteps, door, magic | One-shots (2–4.5 s) | A narrated sentence mentions them |

Format: 22.05 kHz, 16-bit mono WAV, about 3.4 MB in total.
